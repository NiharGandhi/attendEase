# **App Name**: AttendEase

## Core Features:

- Video Feed Display: Display a real-time video feed from the camera.
- Facial Recognition: Detect and recognize faces from the video feed using MEGVII Face++ API. The LLM may use the classroom schedule to reduce the face recognition search space, by pre-filtering on known students.
- Attendance Recording: Record attendance at 5-minute intervals based on recognized faces.
- Attendance Confirmation: Show names and relevant course for successfully identified students

## Style Guidelines:

- Primary color: Deep Blue (#003049) for a professional look.
- Secondary color: Light Gray (#D6D6D6) for backgrounds and neutral elements.
- Accent: Teal (#40E0D0) for interactive elements and highlighting attendance records.
- Clean and structured layout for easy navigation and readability.
- Use simple and recognizable icons for navigation and actions.
- Subtle animations to indicate face detection and attendance confirmation.
